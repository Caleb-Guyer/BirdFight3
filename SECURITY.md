# Security Policy

## Supported Versions

The following versions of Bird Fight 3 currently receive security updates:

| Version | Supported |
| ------- | ---------- |
| Latest release | Yes |
| Development branch (`master`) | Yes |
| Older versions | No |

If you are using an older version, you should update to the latest release to ensure you receive security fixes.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

To report a vulnerability, contact:

**guyercaleb067497@gmail.com**

Please include the following information when reporting:

- A clear description of the issue  
- Steps to reproduce the vulnerability  
- The potential impact  
- Any relevant logs, screenshots, or proof-of-concept code  

You can expect an acknowledgment within 48–72 hours.

If the vulnerability is confirmed:

- A fix will be developed as quickly as possible  
- You may be contacted for additional information  
- You will be notified when the issue is resolved  
- Credit will be given in the release notes unless you request anonymity  

If the vulnerability is declined:

- You will receive an explanation of why it was not considered a security issue  

---

## Disclosure Policy

Please do not publicly disclose security vulnerabilities until:

- A fix has been released, or  
- You have received explicit permission to disclose  

Coordinated disclosure helps protect users of the project.

---

## Scope

This policy applies to:

- The Bird Fight 3 codebase  
- Build scripts and distribution packages  
- Configuration files included in the repository  

It does not apply to:

- Third-party libraries  
- User-created mods or forks  
- External services not controlled by this project  

---

## Thank You

Responsible disclosure helps keep the project and its users safe.  
Thank you for taking the time to report security issues.
