## How to use this report

Combat rounds below 40% deserve review; 40–70% is the initial target band; results above 70% may be too easy. Compare this report with the ordinary roster audit: weakness in both points to the fighter, while weakness only here points to the authored Classic encounter. Objective rounds measure AI routing as much as balance.
